BSDO 0.3.0

Battery Swap Domain Ontology — frozen release

This is the target of the version identifier https://w3id.org/bsdo/0.3.0. It supersedes 0.2.0, which remains available at its own identifier.

These files do not change. A version identifier has to keep resolving to the release it names, so that an ontology or dataset which declared an import of this version still resolves to what it was written against after later releases change the files at the root.

For the current release, see the ontology home page.

What changed since 0.2.0

  • Every class carries a derivationPath annotation naming its provenance: lattice, composed, reuse, or structural.
  • The lithium iron phosphate chemistry value is aligned to the EMMO chemical-substance module.
  • Individuals carry a source annotation recording what each value was read from.
  • owl:priorVersion points back to 0.2.0.
